# GEO Audit Report: Сибирские газоны (gazony.ru)

**Дата аудита:** 2026-06-11
**URL:** https://gazony.ru
**Тип бизнеса:** локальный бизнес (питомник + садовые центры) с услугами озеленения, каталогом растений и блогом (гибрид Local Business / Services / E-commerce)
**Страниц проанализировано:** 20+ (главная, все разделы из pages/urls.py, выборка категорий каталога и статей)

---

## Executive Summary

**Overall GEO Score: 37/100 (Critical)**

Сайт имеет сильную техническую базу для AI-видимости: контент рендерится сервером (Django SSR) и полностью доступен любым краулерам без JS, ни один AI-бот не заблокирован. Но на этом фундаменте почти ничего не построено: нет robots.txt, sitemap.xml, llms.txt, JSON-LD, OG-тегов и canonical; статьи блога на проде - индексируемые заглушки с текстом «(заглушка)»; страницы «О компании» не существует; рейтинг 3.2 на 2ГИС (69 отзывов) - главный «голос бренда», который AI-системы цитируют вместо сайта. Сейчас AI-ассистенты узнают о компании из агрегаторов (2ГИС, Zoon, orgpage), а не с gazony.ru.

## Critical Issues (исправить немедленно)

1. **Статьи-заглушки индексируются на проде.** `/stati/kak-ukladyvat-gazon/`, `/stati/osobennosti-klimata-sibiri/`, `/stati/vybor-rasteniy-dlya-tene/` отдают 200 с H1 «Заголовок статьи (заглушка)». Это худший сигнал качества для поисковиков и AI. Фикс: noindex (или 410) сегодня, затем наполнение, начиная со статьи про сроки укладки газона в Сибири.
2. **Нет robots.txt и sitemap.xml** (оба 404). Краулеры не получают карту сайта, нечего сабмитить в Яндекс.Вебмастер / Bing. Фикс: `django.contrib.sitemaps` + route для robots.txt в `pages/urls.py` (по конвенции проекта - через Django, не через docs/). В robots.txt явно разрешить GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, YandexBot и сослаться на sitemap.
3. **404 по проиндексированным URL старого сайта без 301-редиректов.** `/company/`, `/advice/blagoustroystvo/...`, `/services/ustroystvo-gazonov/` до сих пор в индексе и отдают 404. Теряется накопленный авторитет домена, AI-системы бьются в мёртвые ссылки. Фикс: карта 301-редиректов старая структура -> новая (`/company/` -> страница о компании, `/services/ustroystvo-gazonov/` -> `/gazon/`).
4. **Полное отсутствие структурированных данных (Schema: 5/100).** 0 блоков JSON-LD, microdata, OG на всех проверенных страницах. Сущность «Сибирские газоны» машиночитаемо не связана с gazony.ru ни для одной AI-платформы.
5. **Два MP4 по ~20 МБ на главной с autoplay и preload="auto"** (~42 МБ видео при первом заходе). Прямой удар по LCP и мобильному трафику. Фикс: preload="none" + poster + запуск по IntersectionObserver, пережать до 2-3 МБ.

## High Priority Issues

1. **Нет страницы «О компании».** Ссылка в футере «Блок о компании» ведёт на якорь главной. Нет истории (компания основана в 1999, этот факт живёт только в агрегаторах), команды, реквизитов на видном месте.
2. **Один meta description на весь сайт** (хардкод в base.html), нет canonical, шаблонные title у статей. Нужны уникальные title/description per page из pages/data.py + блоки в base.html.
3. **GitHub Pages зеркало без noindex и canonical** (fixxxxxus.github.io/sib_khvoinik_test/ отдаёт 200 с полной копией главной). Риск склейки дубля не в ту сторону. Фикс: noindex в экспорт-скриптах (или отключить Pages) + self-canonical на gazony.ru.
4. **Нулевое авторство и анонимная экспертиза.** Агрономическая фактура есть (календарь ухода на 115 растений, тезисы о сибирском климате), но ни одного названного специалиста. Нужны страницы/блоки авторов + Person schema.
5. **Полное отсутствие цен на сайте.** Ни одного рубля на 12 ключевых страницах - всё за формами «Узнать цену». Проигрыш по коммерческим интентам и нулевая цитируемость для AI-ответов о ценах.
6. **Несогласованный NAP.** В справочниках минимум 4 адреса и 3 разных телефона (913 756-90-16 / 383 201-06-00 / 383 381-11-00). AI не может надёжно связать карточки с сайтом. Консолидировать карточки Яндекс Карт и 2ГИС, привести к актуальным данным.
7. **Рейтинг 3.2 на 2ГИС (69 отзывов)** - главный отзывный сигнал, который процитирует AI по запросу «питомник Новосибирск отзывы». Отвечать на негатив, системно собирать отзывы (встроить в Службу заботы).
8. **Tailwind компилируется в браузере**: 407 КБ render-blocking JS в head. Заменить на пребилд CSS (standalone Tailwind CLI). Lucide с unpkg - self-host с defer.
9. **Нет HSTS**, нет дат публикации/обновления нигде на сайте, нет llms.txt.

## Medium Priority Issues

1. Нет FAQ-блоков с разметкой FAQPage (данные для /gazon/ уже готовы в `GAZON_PAGE["faq"]`).
2. /catalog/ - «Каталог разрабатывается!»: голый список культур без описаний и цен (citability 18/100).
3. Кейсы ЖК («Инские холмы», «Чикаго», «Флора и Фауна») без цифр: нет площадей, сроков, года реализации.
4. Календарь ухода (сильнейший уникальный актив, 115 растений) собирается скриптом - текст задач невидим краулерам без JS. Нужен SSR-вывод.
5. Голая 404-страница Django («Not Found», 179 байт, на английском). Нужен templates/404.html.
6. JPEG-изображения по 240-480 КБ (садовые центры, постеры) - дожать в WebP; нет loading="lazy" и width/height на img (риск CLS).
7. Нет верификации Bing (msvalidate) и IndexNow; в HTML нет yandex-verification (если подтверждено через DNS - ок).
8. Юрлицо ООО «Сибирский хвойник» ИНН 5406843096 только в политике конфиденциальности - вынести реквизиты в футер/контакты.
9. Нет CSP; домены sibgazony.ru и sibgarden.ru перехватывают брендовые запросы - выяснить, свои или чужие.

## Low Priority Issues

1. Цифры на главной упакованы в счётчики («200 / гектаров»), а не в цитируемые предложения.
2. Эмодзи в H2, пустые h3 в шаблонах - шум в семантике заголовков.
3. Двойной редирект http://www -> https://www -> apex (поправить в Caddyfile.full).
4. Нет явного Cache-Control для HTML.
5. «Сибирский Хвойник» как внешний бренд не использовать: в вебе сущность нулевая, путается с эфедрой и чужими питомниками.
6. YouTube-канал заброшен (~2020), Дзен-публикаций нет, в ruspitomniki.ru компании нет.

На всём сайте ни одного FAQ-блока и ни одного определения формата «Рулонный газон - это...». AI цитирует самодостаточные абзацы из 2-3 предложений с цифрами - таких на сайте почти нет.

### Content E-E-A-T (44/100)

Experience 14/25: реальные мощности и кейсы ЖК есть, но без измеримых результатов. Expertise 8/25: агрономическая фактура анонимна, ноль авторства. Authoritativeness 6/25: нет страницы «О компании», истории, команды. Trustworthiness 16/25: HTTPS, полные контакты, юрлицо в политике, ЭДО для B2B - но ни одной цены, ни одного отзыва, ни одной даты публикации. Блог не отвечает ни на один ключевой вопрос сибирского садовода (когда стелить газон, чем укрывать хвойные, снежная плесень, зоны морозостойкости) - при том что внутренняя экспертиза для этих тем уже есть в календаре ухода.

### Technical GEO (60/100)

Сильные стороны: SSR (текст доступен без JS), все AI-краулеры получают 200 без клоакинга, HTTP/2 + HTTP/3, zstd-сжатие (188 КБ -> 29.5 КБ), образцовое кэширование статики, корректные редиректы, чистые URL, все 13 ключевых страниц - 200. Слабые: нет robots/sitemap/llms.txt, TTFB ~0.9-1.0 с (жёлтая зона), 42 МБ автозагружаемого видео на главной, render-blocking Tailwind 407 КБ, нет HSTS/CSP, голая 404, Pages-зеркало без noindex.

### Schema & Structured Data (5/100)

Разметки нет вообще (0 JSON-LD / microdata / OG / RDFa на всех проверенных страницах). План внедрения и готовые JSON-LD примеры с реальными данными компании (Organization + ООО «Сибирский хвойник» ИНН 5406843096, GardenStore x2 для МЕГА и Новопичугово с режимом работы, Product/Offer для ~900 растений каталога, FAQPage из готового GAZON_PAGE["faq"], BreadcrumbList, Article) - подготовлены субагентом geo-schema; точки вставки: новый partial `templates/partials/schema_org.html` + `{% block structured_data %}` в base.html, далее plant-card.html, gazon.html, stati-detail.html.

## Quick Wins (внедрить на этой неделе)

1. **noindex на статьи-заглушки** - один атрибут в шаблоне, убирает худший сигнал качества (15 минут).
2. **robots.txt + sitemap.xml через Django** - `django.contrib.sitemaps` + path в pages/urls.py; разрешить AI-ботов, сослаться на sitemap (2-3 часа).
3. **Глобальный JSON-LD @graph в base.html** - Organization + GardenStore x2 + WebSite (заготовка от субагента готова, данные в pages/data.py есть) + self-canonical + OG-теги (полдня).
4. **301-редиректы со старых URL** (/company/, /advice/..., /services/...) - десяток строк в urls.py или Caddyfile (1-2 часа).
5. **Выключить автозагрузку 2x20 МБ видео на главной** - preload="none" + poster (1 час).
