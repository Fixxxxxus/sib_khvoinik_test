Описание
Вариант и цена
Анемона гибридная "Серенада" — популярный сорт японской ветреницы, ценящийся за обильное и продолжительное осеннее цветение. Цветки: полумахровые, розового или темно-розового цвета с ярко-желтой серединой из тычинок. Высота: взрослое растение достигает 60–100 см. Период цветения: с августа по сентябрь/октябрь. Считается одним из самых долгоцветущих многолетнико
